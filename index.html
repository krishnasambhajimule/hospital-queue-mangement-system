Local Setup Guide

How to Run & Deploy in VS Code

Follow these simple steps to run this application locally on your computer with full functionality.

1

Create Index File

Create a folder on your computer (e.g. hospital-queue) and save this file inside as index.html.

2

Open in VS Code

Open the folder in Visual Studio Code. Install the official Live Server extension if not already installed.

3

Launch Application

Right-click index.html and click "Open with Live Server" or double click to launch directly in any browser.
